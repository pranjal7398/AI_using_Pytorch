<h3>Gemini API Project</h3>

This project demonstrates the use of the **Google Gemini API** to generate AI-powered responses. The project securely accesses the Gemini API key using **Google Colab Secrets**, ensuring that the API key is not exposed when the project is shared on GitHub.

The application sends user input to the Gemini model through the Gemini API and displays the generated response.
